# PRD

## Vision
A habit app that makes behavior change visible, forgiving and science-based, so users see real improvements in their lifestyle.

## Target users
1. The founder (personal use, Phase 1).
2. Spanish-speaking adults (LatAm + Spain) who have tried habit apps and quit. English second.
3. Couples who want to build habits together (Pro Parejas).

## Core features (MVP)
- Create/edit habits: name, icon, color, frequency (daily, every N days, specific weekdays, every N hours within a window), optional time window.
- **Hoy** view: pending/done habits grouped by day band (morning / afternoon / night), one-tap check-in with animation + haptics.
- **Semana** view: Monday–Sunday × hours grid, day bands visually distinct, done vs. pending.
- Local reminders.

## Next features
- Identity Tree (garden) + dynamic sky.
- Stats: daily rings, weekly trend, monthly heatmap, completion rate per day band, 1% curve.
- Habit stacking (Trigger → Action) and context cues.
- 2-minute version, implementation intentions, temptation bundling.
- AI habit coach (daily check-in, weekly review).
- Pro Parejas: individual + shared weekly habits, cheers, nudges, joint streak, intertwined trees.

## Success metrics
- D30 retention; % of habits that reach 66 days; weekly consistency trend per user.
- Self-reported lifestyle improvement (periodic in-app survey).
